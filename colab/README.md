# Screenwise: three-person Colab version

1. Create one Google Colab notebook in your Google Drive.
2. Share it with your two friends using their Google-account email addresses and Editor access. GitHub usernames do not grant Colab access.
3. Add three code cells. Abhinav pastes Part 1, Nehanth185 pastes Part 2, and Sreel712 pastes Part 3. The Markdown documents have copyable code blocks; matching Word documents are also provided.
4. Run all three cells in order in the same runtime. After a runtime reset, rerun all three. No GPU or API key is needed. Internet access is needed for the public CSV.
5. In Part 3, change record_number or threshold and rerun that cell to demonstrate the result. Use only the provided public records.
6. Download the write-up and test evidence from the Colab Files sidebar.

Alternatively, open Screenwise_Team.ipynb in Colab and save a copy in Drive. It already contains all three parts.

The full code was executed sequentially in Python and reproduced the original results. Colab browser UI was not tested. Word code was read back and verified against the source.

These roles are suggested work assignments, not claims that each person has already written or completed that part. Review and adapt your code, and follow the competition's AI-assistance rules.

This project is a prototype and is not medical advice.
